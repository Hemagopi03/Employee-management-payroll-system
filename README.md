# Employee Management and Payroll System

Python Tkinter + MySQL desktop application.

## Features
- Login / Register
- Employee Management (Add / View)
- Salary Payment with Net Salary Calculation
- Payment History
- Report (Total Employees, Payments, Total Salary)

## Tech Stack
- Python, Tkinter
- MySQL

## How to Run
1. Install MySQL and create database `employee_payment`
2. Run SQL file `employee_payment.sql`
3. `pip install mysql-connector-python`
4. Update DB password in `database.py`
5. `python login.py`

## Formula
`net_salary = basic_salary + allowance - deduction`

## Report
Full report available in `/report` folder.
